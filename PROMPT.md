# Проект: PWA-приложение для автосервиса "BVK-AUTOSERVIS + МирГбоСПб"

## Текущее состояние (Светлый UI в стиле Bumpix)
- **Стек:** React, TypeScript, Vite, Tailwind CSS.
- **Дизайн:** Светлая тема, минимализм. Никаких Bottom Bar. Навигация построена на sticky-шапке и плавающей нижней панели действий (fixed bottom-0).
- **Структура:** Два направления в одном приложении (слесарный ремонт и ГБО), переключение через табы в шапке.

## Два режима работы
1. **Клиентская часть (Запись клиента):** Каталог услуг, выбор услуг (с подсчетом суммы и времени), переход к выбору слота времени и оформлению заявки.
2. **Журнал мастера (Админка):** Скрытый раздел для управления расписанием, просмотра записей клиентов, настройки услуг и рабочего графика. 

## Архитектурные задачи (Переход на Supabase)
- Сейчас приложение работает как монолит (весь код и замоканные данные лежат в `src/App.tsx`).
- **Главная цель текущего этапа:** Декомпозиция `App.tsx` и перенос базы данных (услуги, записи, клиенты) в Supabase.
- **RLS и Авторизация:** Журнал мастера должен быть скрыт за Supabase Auth. Клиенты имеют права только на чтение услуг и создание записи. Мастер имеет полный CRUD доступ ко всем таблицам.
